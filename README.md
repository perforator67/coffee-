# Тишь — сайт-визитка спешелти-кофейни

Одностраничный сайт вымышленной кофейни с собственной обжаркой. Работа для портфолио.

## Как открыть

Двойной клик по `index.html`. Сборка и установка не нужны. Интернет нужен только для шрифтов Google Fonts — без него сайт откроется с системными шрифтами.

## Что внутри

```
index.html        разметка: шапка, hero, о кофейне, меню, атмосфера, контакты, футер
css/style.css     стили (mobile-first, CSS-переменные, брейкпоинты 760 и 1040 px)
js/main.js        липкая шапка, мобильное меню, появление при скролле, параллакс, статус «открыто»
assets/logo.svg   логотип (знак + название)
assets/favicon.svg
```

## Концепция

- **Название:** «Тишь». Одно слово, которое обещает главное — паузу.
- **Слоган:** «Кофе, который не торопит».
- **Логотип:** круг (чашка сверху) с S-образным швом кофейного зерна, тонкая линия. Читается в 16 px.
- **Палитра:** тёплый белый `#FBF9F6`, молочный `#F6F2EC`, белый `#FFFFFF`, графит `#2A2623`, вторичный `#7A726A`, эспрессо `#3B2A20`, латунь `#B08D6A`, линии `#E7E0D6`. Других цветов нет.
- **Шрифты:** Cormorant Garamond (заголовки, светлое начертание и курсив) + Manrope (текст и интерфейс).
- **Иллюстрации:** чашка с паром, воронка V60, зёрна, схема проезда — всё нарисовано вручную в SVG, внешних изображений нет.
- **Контент вымышленный:** адрес (Льняной переулок, 7), телефон +7 (812) 407-19-26, почта и соцсети — заглушки.

## Референсы

Смотрел подборки и карточки сайтов кофейных обжарщиков. Часть галерей (DesignRush, карточка шаблона Ochre) не открылась, поэтому по ним опирался на описания из поисковой выдачи, а не на сами макеты.

1. **Coffee Roastery Site, шаблон на Framer Marketplace — главный референс.**
   https://www.framer.com/marketplace/templates/coffee-roastery-site/
   Понравилось: одностраничный ритм, где «история» чередуется с «делом» (история бренда → меню → адрес и часы), и редакционная типографика.
   Перенял: порядок и чередование секций, крупный редакционный заголовок как главный визуальный элемент.
   Адаптировал: вместо «bold» — светлое начертание засечного шрифта; вместо продуктовых фото — линейные SVG-иллюстрации; секции чередуют тёплый белый и молочный фон.

2. **Ceremony Coffee Roasters (обзор DesignRush).**
   Понравилось: светлая, воздушная подача, где кофе в центре, а интерфейс почти не заметен.
   Перенял: много воздуха, простую навигацию из трёх пунктов.

3. **Origin Coffee Roasters и Pilot Coffee (подборки DesignRush и ecomm.design).**
   Понравилось: минимализм и детали, которые раскрываются при наведении.
   Перенял: сдержанные hover-реакции — строка меню чуть сдвигается, карточка приподнимается и получает латунную рамку.

Своё, не из референсов: нумерация секций курсивом (01–04), арка с чашкой в hero, пунктирные лидеры в меню, условная схема проезда, статус «сейчас открыто» по петербургскому времени.

Код, тексты, изображения и названия из референсов не использовались.

## Примечания

- `og:image` не задан: ему нужен абсолютный URL и растровая картинка, а сайт пока нигде не размещён.
- Анимации отключаются при `prefers-reduced-motion`; без JavaScript весь контент виден сразу.
